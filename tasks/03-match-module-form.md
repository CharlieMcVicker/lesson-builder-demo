# Task: Match Module Form

**Phase**: 2
**Goal**: Build the edit-mode form for adding data to a "Match" Module.

## Requirements:

- [ ] Create a `MatchModuleForm` component that receives `MatchModuleData` and an `onChange` callback.
- [ ] Implement settings dropdowns/radios for users to select the "front" and "back" fields (`cherokee`, `phonetics`, `english`).
- [ ] Render the existing `VocabFindCreate` component to let users build a targeted list of vocab items for matching.
- [ ] Save the configuration and associated words into the module's state.
