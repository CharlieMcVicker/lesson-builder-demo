# Task: Sentence Module Form

**Phase**: 2
**Goal**: Build the edit-mode form for the "Build the Sentence" module.

## Requirements:

- [ ] Create a `SentenceModuleForm` component.
- [ ] Provide configuration inputs for the target sentence presentation field and the piecemeal presentation field.
- [ ] Include an interface (using `VocabFindCreate`) to select/create a `VocabItem` representing the full sentence.
- [ ] Include an interface for adding an ordered sequence of `VocabItem`s representing the individual constituent word-parts. Allow reordering of these parts in the editor.
